Заміна багатопроменевої зірки багатокутником

При розрахунку струмів КЗ схеми заміщення містять лише індуктивні опори (x) та ЕРС (Ė) джерел. Перетворення багатопроменевої зірки у повний багатокутник із діагоналями включає визначення як еквівалентних опорів, так і еквівалентних ЕРС кожної сторони.

Формули опорів (n променів)

Опір між вузлами i та j xij = xi · xj · Y1–n
Сумарна провідність Y1–n = Σ (1 / xk) ,   k = 1, 2, …, n

Формула ЕРС сторін багатокутника

При перетворенні зірки з ЕРС у багатокутник кожна сторона (діагональ) отримує еквівалентну ЕРС. Для забезпечення еквівалентності при будь-якому зовнішньому навантаженні, ЕРС сторони між вузлами i та j визначається як різниця ЕРС відповідних променів:

ЕРС сторони багатокутника між вузлами i та j Ėij = Ėi − Ėj

Ця формула є загальною для будь-якої кількості n променів. Вона випливає з умови еквівалентності: при будь-яких зовнішніх напругах на затискачах, струми в зовнішньому колі мають бути однаковими для зірки і багатокутника. Додаткова умова — відсутність зрівняльних струмів (сума ЕРС в кожному замкненому контурі багатокутника дорівнює нулю).

Фізичний зміст: ЕРС сторони Ėij = Ėi − Ėj показує «рушійну силу» між двома джерелами. Якщо Ėij > 0, це означає що джерело i «сильніше» за j, і еквівалентна ЕРС штовхає струм від i до j. Якщо ЕРС генераторів мало відрізняються, еквівалентні ЕРС сторін будуть малими.

Напрямок ЕРС у сторонах багатокутника

Еквівалентна ЕРС Ėij спрямована від вузла i до вузла j, тобто «штовхає» струм від джерела з більшою ЕРС до джерела з меншою. Від'ємне значення Ėij означає, що реальний напрямок ЕРС протилежний — від j до i.

Перевірка — контурні рівняння

Оскільки ЕРС визначені за умови відсутності зрівняльних струмів, алгебраїчна сума ЕРС в будь-якому замкненому контурі має дорівнювати нулю (другий закон Кірхгофа при I=0). Обходимо контур послідовно: якщо напрямок ЕРС збігається з обходом — беремо «+», якщо протилежний — «−». Наприклад, у контурі 1→2→3→1: Ė₁₂ і Ė₂₃ збігаються з обходом, а Ė₁₃ має напрямок 1→3, що протилежний поверненню 3→1, тому віднімаємо.

Контур 1-2-3: Ė₁₂ + Ė₂₃ − Ė₁₃ = 0.050 + (−0.020) − 0.030 = 0 ✓
Контур 1-2-4: Ė₁₂ + Ė₂₄ − Ė₁₄ = 0.050 + 0.030 − 0.080 = 0 ✓
Контур 1-3-4: Ė₁₃ + Ė₃₄ − Ė₁₄ = 0.030 + 0.050 − 0.080 = 0 ✓
Перевірка — вузлові рівняння

Ця перевірка гарантує, що струми в еквівалентному багатокутнику відповідають струмам вихідної зірки при будь-якому зовнішньому навантаженні. Для кожного вузла k виконується рівняння балансу: сума відношень Ėkj/xj по всіх сусідніх вузлах j має дорівнювати Y·Ėk − S, де S = Σ(Ėm/xm) — сума по всіх променях. По суті, ми перевіряємо, що напруга вузла центру зірки V₀ правильно відтворюється багатокутником.

Σ(Ėm/xm) = 1.13/0.10 + 1.08/0.20 + 1.10/0.25 + 1.05/0.50 = 11.30 + 5.40 + 4.40 + 2.10 = 23.20

Вузол 1: Ė₁₂/x₂ + Ė₁₃/x₃ + Ė₁₄/x₄ = 0.050/0.20 + 0.030/0.25 + 0.080/0.50
  = 0.250 + 0.120 + 0.160 = 0.530
  Y·Ė₁ − S = 21.0 × 1.13 − 23.20 = 23.73 − 23.20 = 0.530 ✓

Перевірка — контурні рівняння

Обираємо будь-які незалежні трикутні контури багатокутника і перевіряємо, що алгебраїчна сума ЕРС при обході контуру = 0. Згортання багатокутника та розрахунок надперехідного струму

Після перетворення зірки в багатокутник далі спрощуємо схему, щоб отримати еквівалентну гілку між двома вузлами. Це дозволяє визначити надперехідний зрівняльний струм між відповідними джерелами.

Метод послідовного виключення вузлів

Виключення вузла k зі схеми — це перетворення зірки, утвореної гілками у вузлі k, в багатокутник між його сусідами. Використовується та сама формула:

Новий опір між вузлами i та j (через виключений вузол k) xij(нов) = xik · xjk · Yk    де Yk = Σ(1/xmk) — сума провідностей усіх гілок у вузлі k

Якщо між вузлами i та j вже існує гілка, нову та стару з'єднуємо паралельно:

Паралельне з'єднання існуючої та нової гілки xij(рез) = xij(стар) · xij(нов) / (xij(стар) + xij(нов))

Еквівалентна ЕРС та надперехідний струм

Оскільки Ėij = Ėi − Ėj і ця формула не залежить від проміжних вузлів, еквівалентна ЕРС після повного згортання залишається різницею ЕРС двох кінцевих генераторів:

Еквівалентна ЕРС та зрівняльний струм Ėекв(i→j) = Ėi − Ėj
I″ij = Ėекв / xекв = (Ėi − Ėj) / xекв(i→j)
Перевірка через теорему Тевеніна: При розімкнутих клемах струм у зірці не тече, тому напруга холостого ходу між вузлами i та j дорівнює Vij = Ėi − Ėj. В еквівалентному багатокутнику сума ЕРС по контуру = 0, отже циркулюючих струмів немає, і напруга на клемах i–j дорівнює ЕРС цієї гілки. Для еквівалентності: Ėij = Ėi − Ėj.

Крок 3 — Виключення вузла 3 (трикутник → одна гілка)

Вузол 3 з'єднаний з вузлами 1 та 2:

Провідність у вузлі 3 Y₃ = 1/0.387 + 1/0.725 = 2.586 + 1.379 = 3.966
x₁₂нов = 0.387 × 0.725 × 3.966 = 1.112

xекв(1→2) = 0.290 ‖ 1.112 = 0.290 × 1.112 / (0.290 + 1.112) = 0.230 в.о.

Результат

Еквівалентний опір між вузлами 1 та 2 xекв(1→2) = 0.230 в.о.
Перевірка: xекв = 0.230 = x₁ + x₂ = 0.08 + 0.15. Це логічно — еквівалентний опір між вузлами 1 та 2 дорівнює послідовному з'єднанню їх променів через центр зірки (прямий шлях), паралельно з обхідними шляхами через інші вузли. В даному випадку обхідні шляхи мають значно більший опір і практично не змінюють результат.
Еквівалентна ЕРС (різниця ЕРС генераторів) Ėекв = Ė₁ − Ė₂ = 1.13 − 1.10 = 0.030 в.о.
Надперехідний зрівняльний струм між генераторами 1 та 2 I″12 = Ėекв / xекв = 0.030 / 0.230 = 0.130 в.о.
Фізичний зміст: Зрівняльний струм I″₁₂ = 0.130 в.о. протікає між генераторами 1 та 2 під час перехідного процесу через різницю їх надперехідних ЕРС (Ė₁=1.13 проти Ė₂=1.10). Цей струм відносно малий, оскільки ЕРС генераторів відрізняються лише на 0.03 в.о. — генератори працюють в близьких режимах. При більшій розбіжності ЕРС (наприклад, при різному збудженні) зрівняльний струм зростав би пропорційно.
Роль паралельних шляхів: xекв = 0.230 в.о. менший за прямий опір гілки багатокутника x₁₂ = 0.360 в.о. Це пояснюється тим, що окрім прямої гілки 1–2 існують обхідні шляхи через вузли 3, 4, 5, які з'єднані паралельно і зменшують загальний опір.

Чотирикутник без діагоналей — КЗ в точці К на стороні 3–4

Дано: Схема заміщення у вигляді чотирикутника (кільцева мережа). Генератори з ЕРС розташовані у вузлах 1, 3 та 4. Вузол 2 — навантаження (без генератора).

2–3x₂₃ = 0.45
3–4x₃₄ = 0.50
4–1x₄₁ = 0.40

Точка КЗ: Трифазне КЗ в точці К на стороні 3–4, яка ділиться на x₃K = 0.30 та xK₄ = 0.20.

Потрібно: Знайти надперехідний струм КЗ I″K методом послідовного згортання.

Вихідна схема: чотирикутник з точкою КЗ на стороні 3–4
Крок 1 — Виключення вузла 2-навантаження (послідовне з'єднання)

Вузол 2 — навантаження без власного генератора, має лише два з'єднання. З'єднуємо гілки 1–2 та 2–3 послідовно:

x₁₃ = x₁₂ + x₂₃ = 0.35 + 0.45 = 0.80
Після виключення навантаження (вузол 2) → чотирикутник 1–3–K–4
Крок 2 — Виключення генератора у вузлі 1 (Ė₁ = 1.13)

Вузол 1 — генератор (ідеальне джерело напруги з'єднане з нейтраллю). Він утримує потенціал V₁ = Ė₁ = 1.13 незалежно від струму. Вузол 1 з'єднаний з двома сусідніми генераторними вузлами:

Струми від генератора 1 до сусідів I₁₃ = (Ė₁ − Ė₃) / x₁₃ = (1.13 − 1.10) / 0.80 = 0.038 в.о.  (перетік до ген. 3)
I₁₄ = (Ė₁ − Ė₄) / x₄₁ = (1.13 − 1.05) / 0.40 = 0.200 в.о.  (перетік до ген. 4)

Ці струми є зрівняльними між генераторами і замикаються через нейтраль. Вони не досягають точки К, оскільки вузли 3 та 4 — ідеальні джерела, які підтримують свої напруги (V₃ = Ė₃, V₄ = Ė₄) незалежно від вхідного струму. Генератор 1 повністю «екранований» від точки КЗ генераторами 3 та 4.

Висновок: Генератор Ė₁ = 1.13 не впливає на напругу в точці К і не вносить вклад у струм КЗ. Його зрівняльні струми замикаються між генераторами, не проходячи через точку К. Після виключення вузла 1 залишається ділянка 3–К–4 з двома генераторами по боках.
Після виключення генератора 1 → ділянка 3–К–4 (два шляхи до землі)
Крок 3 — Визначення двох шляхів від К до землі

Точка К з'єднана з двома заземленими генераторами. Кожен генератор забезпечує окремий шлях від К до нейтралі:

Шлях 1: К → генератор 3 (ліворуч) x = x₃K = 0.30,   ЕРС = Ė₃ = 1.10

Шлях 2: К → генератор 4 (праворуч) x = xK₄ = 0.20,   ЕРС = Ė₄ = 1.05

Напруга холостого ходу в точці К (до КЗ):

V_K — напруга в точці К без КЗ I₃₄ = (Ė₃ − Ė₄) / x₃₄ = (1.10 − 1.05) / 0.50 = 0.10 в.о.
VK = Ė₃ − I₃₄ · x₃K = 1.10 − 0.10 × 0.30 = 1.07 в.о.
Перевірка: VK = Ė₄ + I₃₄ · xK₄ = 1.05 + 0.10 × 0.20 = 1.07 ✓

Крок 4 — Паралельне з'єднання двох шляхів

Точка К з'єднана з землею двома паралельними шляхами — через генератор 3 (x=0.30, Ė₃=1.10) та через генератор 4 (x=0.20, Ė₄=1.05). Зводимо до одного еквівалентного джерела Тевеніна:

Еквівалентний опір (паралельне з'єднання) xекв = x₃K ‖ xK₄ = 0.30 × 0.20 / (0.30 + 0.20) = 0.120 в.о.
Еквівалентна ЕРС (зважене середнє) Ėекв = (Ė₃/x₃K + Ė₄/xK₄) / (1/x₃K + 1/xK₄)
   = (1.10/0.30 + 1.05/0.20) / (1/0.30 + 1/0.20)
   = (3.667 + 5.250) / (3.333 + 5.000)
   = 8.917 / 8.333 = 1.070 в.о.
Зверніть увагу: Ėекв = 1.070 — це зважене середнє ЕРС генераторів, де вага кожного генератора обернено пропорційна опору шляху від нього до точки КЗ. Генератор 4 (ближчий, x=0.20) впливає більше, ніж генератор 3 (дальший, x=0.30).

Надперехідний струм КЗ

Надперехідний струм КЗ в точці К I″K = Ėекв / xекв = 1.070 / 0.120 = 8.917 в.о.
Зведена таблиця результатів xекв = 0.120 в.о.  |  Ėекв = 1.070 в.о.  |  I″K = 8.917 в.о.
Перевірка — внески кожного генератора

Струм КЗ складається з внесків генераторів, що безпосередньо прилягають до точки КЗ:

I″3→K = Ė₃ / x₃K = 1.10 / 0.30 = 3.667 в.о.  (від генератора 3)
I″4→K = Ė₄ / xK₄ = 1.05 / 0.20 = 5.250 в.о.  (від генератора 4)

I″K = 3.667 + 5.250 = 8.917 в.о. ✓
Фізичний зміст: Генератор 4 дає 59% струму КЗ (5.250 з 8.917), хоча його ЕРС менша (1.05 < 1.10). Це пояснюється тим, що він ближчий до точки КЗ (xK₄=0.20 vs x₃K=0.30). Генератор 1 (Ė₁=1.13) не вносить прямого внеску, оскільки його шлях до К проходить через уже заземлені вузли 3 та 4. Навантаження у вузлі 2 не впливає на струм КЗ (воно виключене на першому кроці).
