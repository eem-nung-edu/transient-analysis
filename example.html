Заміна багатопроменевої зірки багатокутником

При розрахунку струмів КЗ схеми заміщення містять лише індуктивні опори (x) та ЕРС (Ė) джерел. Перетворення багатопроменевої зірки у повний багатокутник із діагоналями включає визначення як еквівалентних опорів, так і еквівалентних ЕРС кожної сторони.

Формули опорів (n променів)

Опір між вузлами i та j xij = xi · xj · Y1–n
Сумарна провідність Y1–n = Σ (1 / xk) ,   k = 1, 2, …, n

Формула ЕРС сторін багатокутника

При перетворенні зірки з ЕРС у багатокутник кожна сторона (діагональ) отримує еквівалентну ЕРС. Для забезпечення еквівалентності при будь-якому зовнішньому навантаженні, ЕРС сторони між вузлами i та j визначається як різниця ЕРС відповідних променів:

ЕРС сторони багатокутника між вузлами i та j Ėij = Ėi − Ėj

Ця формула є загальною для будь-якої кількості n променів. Вона випливає з умови еквівалентності: при будь-яких зовнішніх напругах на затискачах, струми в зовнішньому колі мають бути однаковими для зірки і багатокутника. Додаткова умова — відсутність зрівняльних струмів (сума ЕРС в кожному замкненому контурі багатокутника дорівнює нулю).

Фізичний зміст: ЕРС сторони Ėij = Ėi − Ėj показує «рушійну силу» між двома джерелами. Якщо Ėij > 0, це означає що джерело i «сильніше» за j, і еквівалентна ЕРС штовхає струм від i до j. Якщо ЕРС генераторів мало відрізняються, еквівалентні ЕРС сторін будуть малими.

Напрямок ЕРС у сторонах багатокутника

Еквівалентна ЕРС Ėij спрямована від вузла i до вузла j, тобто «штовхає» струм від джерела з більшою ЕРС до джерела з меншою. Від'ємне значення Ėij означає, що реальний напрямок ЕРС протилежний — від j до i.

Перевірка — контурні рівняння

Оскільки ЕРС визначені за умови відсутності зрівняльних струмів, алгебраїчна сума ЕРС в будь-якому замкненому контурі має дорівнювати нулю (другий закон Кірхгофа при I=0). Обходимо контур послідовно: якщо напрямок ЕРС збігається з обходом — беремо «+», якщо протилежний — «−». Наприклад, у контурі 1→2→3→1: Ė₁₂ і Ė₂₃ збігаються з обходом, а Ė₁₃ має напрямок 1→3, що протилежний поверненню 3→1, тому віднімаємо.

Контур 1-2-3: Ė₁₂ + Ė₂₃ − Ė₁₃ = 0.050 + (−0.020) − 0.030 = 0 ✓
Контур 1-2-4: Ė₁₂ + Ė₂₄ − Ė₁₄ = 0.050 + 0.030 − 0.080 = 0 ✓
Контур 1-3-4: Ė₁₃ + Ė₃₄ − Ė₁₄ = 0.030 + 0.050 − 0.080 = 0 ✓
Перевірка — вузлові рівняння

Ця перевірка гарантує, що струми в еквівалентному багатокутнику відповідають струмам вихідної зірки при будь-якому зовнішньому навантаженні. Для кожного вузла k виконується рівняння балансу: сума відношень Ėkj/xj по всіх сусідніх вузлах j має дорівнювати Y·Ėk − S, де S = Σ(Ėm/xm) — сума по всіх променях. По суті, ми перевіряємо, що напруга вузла центру зірки V₀ правильно відтворюється багатокутником.

Σ(Ėm/xm) = 1.13/0.10 + 1.08/0.20 + 1.10/0.25 + 1.05/0.50 = 11.30 + 5.40 + 4.40 + 2.10 = 23.20

Перевірка — контурні рівняння

Обираємо будь-які незалежні трикутні контури багатокутника і перевіряємо, що алгебраїчна сума ЕРС при обході контуру = 0. Правило знаків: ЕРС «+» якщо її напрямок збігається з напрямком обходу, «−» якщо протилежний. Для контуру i→j→k→i: Ėij + Ėjk − Ėik = 0 (бо Ėik спрямована від i до k, а обхід іде від k до i).

Згортання багатокутника та розрахунок надперехідного струму

Після перетворення зірки в багатокутник далі спрощуємо схему, щоб отримати еквівалентну гілку між двома вузлами. Це дозволяє визначити надперехідний струм між відповідними джерелами.

Метод послідовного зведення (Ульянов)

Для n>3 прямої формули ЕРС не існує. Застосовується послідовне об'єднання променів, доки не залишиться 3 промені, після чого використовується формула Ульянова для трикутника:

Формула ЕРС для зірки→трикутник (Ульянов) Ė₁₂ = (Ė₁·(x₂ + x₃) − (Ė₂ + Ė₃)·x₁) / (x₁ + x₂ + x₃)
Ė₂₃ = (Ė₂·(x₁ + x₃) − (Ė₁ + Ė₃)·x₂) / (x₁ + x₂ + x₃)
Ė₃₁ = (Ė₃·(x₁ + x₂) − (Ė₁ + Ė₂)·x₃) / (x₁ + x₂ + x₃)

Об'єднання паралельних променів

Два промені k та m, що підключені до спільного вузла, об'єднуються в один еквівалентний промінь:

Паралельне з'єднання двох променів (з ЕРС) x(km) = xk·xm / (xk+xm)
Ė(km) = (Ėk·xm + Ėm·xk) / (xk+xm)

Згортання трикутника до однієї гілки

Отримавши еквівалентний трикутник з ЕРС, виключаємо третій вузол. Шлях через нього з'єднується послідовно, а потім — паралельно з прямою гілкою. Оскільки сума ЕРС по контуру = 0, ЕРС послідовного шляху дорівнює ЕРС прямої гілки:

x₁₂ = 0.08 × 0.15 × 30.0 = 0.360
x₂₍₃₄₅₎ = 0.15 × 0.0923 × 30.0 = 0.415
x₍₃₄₅₎₁ = 0.0923 × 0.08 × 30.0 = 0.222
Крок 5 — ЕРС сторін трикутника (формула Ульянова)
Ė₁₂ — ЕРС сторони від вузла 1 до вузла 2 Ė₁₂ = (Ė₁·(x₂+x₍₃₄₅₎) − (Ė₂+Ė₍₃₄₅₎)·x₁) / xΣ
   = (1.13×(0.15+0.0923) − (1.10+1.0854)×0.08) / 0.3223
   = (1.13×0.2423 − 2.1854×0.08) / 0.3223
   = (0.2738 − 0.1748) / 0.3223 = 0.307
Ė₂₍₃₄₅₎ — ЕРС сторони від вузла 2 до об'єднаного вузла Ė₂₍₃₄₅₎ = (Ė₂·(x₁+x₍₃₄₅₎) − (Ė₁+Ė₍₃₄₅₎)·x₂) / xΣ
   = (1.10×0.1723 − 2.2154×0.15) / 0.3223 = −0.443
Ė₍₃₄₅₎₁ — ЕРС сторони від об'єднаного вузла до вузла 1 Ė₍₃₄₅₎₁ = (Ė₍₃₄₅₎·(x₁+x₂) − (Ė₁+Ė₂)·x₍₃₄₅₎) / xΣ
   = (1.0854×0.23 − 2.23×0.0923) / 0.3223 = +0.136
Перевірка: Ė₁₂ + Ė₂₍₃₄₅₎ + Ė₍₃₄₅₎₁ = 0.307 + (−0.443) + 0.136 = 0 ✓ — сума ЕРС по замкненому контуру дорівнює нулю.
Проміжний результат: еквівалентний трикутник {1, 2, (345)} — опори та ЕРС (Ульянов)

Етап В. Згортання трикутника до однієї гілки

Крок 6 — Виключення вузла (345)

Вузол (345) з'єднаний з вузлами 1 та 2 двома гілками. Послідовне з'єднання цих гілок дає обхідний шлях від 1 до 2 через (345):

Послідовний опір обхідного шляху xобх = x₍₃₄₅₎₁ + x₂₍₃₄₅₎ = 0.222 + 0.415 = 0.637

ЕРС обхідного шляху: оскільки Ė₁₂ + Ė₂₍₃₄₅₎ + Ė₍₃₄₅₎₁ = 0, ЕРС шляху 1→(345)→2 дорівнює:

Ėобх = −(Ė₂₍₃₄₅₎ + Ė₍₃₄₅₎₁) = −(−0.443 + 0.136) = 0.307 = Ė₁₂ ✓
Крок 7 — Паралельне з'єднання

Пряма гілка та обхідний шлях з'єднуються паралельно. Оскільки їх ЕРС однакові (Ė₁₂ = Ėобх = 0.307), еквівалентна ЕРС не змінюється:

Еквівалентний опір xекв = x₁₂ ‖ xобх = 0.360 × 0.637 / (0.360 + 0.637) = 0.230 в.о.
Еквівалентна ЕРС Ėекв = Ė₁₂ = 0.307 в.о.

Надперехідний струм

Надперехідний зрівняльний струм між генераторами 1 та 2 I″12 = Ėекв / xекв = 0.307 / 0.230 = 1.335 в.о.
Зведена таблиця результатів xекв(1→2) = 0.230 в.о.  |  Ėекв = 0.307 в.о.  |  I″₁₂ = 1.335 в.о.
Фізичний зміст: ЕРС за Ульяновим Ė₁₂ = 0.307 в.о. значно більша за просту різницю Ė₁−Ė₂ = 0.03, оскільки вона враховує перерозподіл ЕРС усіх генераторів у схемі через спільні опори. Надперехідний струм I″₁₂ = 1.335 в.о. відображає реальне навантаження гілки 1–2 під час перехідного процесу.
Роль паралельних шляхів: Еквівалентний опір xекв = 0.230 в.о. менший за прямий опір гілки x₁₂ = 0.360 в.о. завдяки обхідному шляху через об'єднані генератори 3, 4, 5. Цей шлях (xобх = 0.637) з'єднаний паралельно з прямою гілкою.
